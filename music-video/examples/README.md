# Examples

Drop a `song.mp3` and a `clips/` folder here, then run:

```bash
prism cut --song examples/song.mp3 --clips examples/clips --out ./out
```

## Sourcing copyright-free audio

- [Free Music Archive](https://freemusicarchive.org/) — CC-BY catalogue
- [ccMixter](http://ccmixter.org/)
- [YouTube Audio Library](https://studio.youtube.com/) (download as mp3)
- [Pixabay Music](https://pixabay.com/music/) — CC0

## Sourcing clips

Any mix of `.mp4 / .mov / .webm / .jpg / .png` works. 5–60 second clips are ideal;
stills are padded to 2s by default and matched to beats like any other clip.

The repo ships no bundled media — the hackathon rules disallow pre-existing assets
you don't have the rights to.
