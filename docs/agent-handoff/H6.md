# H6 — Physician cohort scale-up (30 to 300 HealthBench Hard examples)

## Dispatch summary

Scale the clinical-rail corpus from 30 examples (hackathon demo) to 300
examples (publishable scale) with a multi-physician adjudication overlay.
The scope covers cohort recruitment, a three-reviewer adjudication protocol
with κ ≥0.6 on safety-critical cases, pipeline scale-up for the larger run,
and a refreshed baseline + harness sweep on the full 300-example subset.
Ships as an expanded corpus, an adjudication overlay file, refreshed
results, and a main-text table replacement for the H3 preprint.

## Notes for the dispatcher

- **IRB / privacy review.** Cohort recruitment requires IRB or equivalent privacy-review clearance before reviewers are contacted. HealthBench Hard is OpenAI-published, contains no PHI by construction (per `docs/clinical-handling.md` §4), and the adjudication is at the rubric level — not patient-level — so the IRB ask is usually minimal, but the dispatcher confirms this path is cleared before recruitment starts.
- **Reviewer honoraria process.** The $1500 API ceiling is the agent-spend cap; reviewer honoraria are separately administered by the dispatcher and do not run through any Prism script.
- **Physician sign-off.** The clinical director named in `docs/clinical-handling.md` §5 is one of the three reviewers by default; the other two are recruited externally.
- **Kappa threshold.** κ ≥0.6 on safety-critical cases is the publishable floor per roadmap §7 H6. If the overlay falls short, adjudication protocol iterates before the corpus ships — not after.
- **Scope guard.** This task expands the HealthBench Hard subset to 300. The full 5,000-example run is NOT in scope here; B6 explicitly defers that further out.
