# H4 — Public harness skeleton release (prism-skel)

## Dispatch summary

Prepare a public companion repository, `prism-skel`, carrying the harness
structure but none of the Prism-private content. Ships the 6-agent template
YAMLs, the JSON Schemas, the double-gate + SDK-containment patterns, and a
`hello_world` example case — Apache 2.0 licensed. Deliberately excludes the
GPU reproducer corpus, the HealthBench Hard selections, and any results.
A third party can clone the skeleton, run `make verify-all`, and get green
on a fresh machine without touching any private material.
